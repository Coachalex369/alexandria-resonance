# Roadmap

Directions under consideration. None of this is a commitment or a schedule.

- **Crystal Metropolis**: a more cinematic direction for the artwork, with denser structures, richer lighting and
  camera work for long sessions.
- **Live mode and collector**: better handling of chained commands, clearer session naming, and richer content-free
  signals from the collector (for example more reliable commit and verification detection).
- **Music**: more voices and arrangements, and export of a performance as MIDI or audio.
- **Packaging**: signed production builds for Windows and a documented install path.
- **Accessibility and performance**: further quality scaling for lower-powered machines.
